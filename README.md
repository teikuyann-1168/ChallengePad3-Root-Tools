-----------------------
ChallengePad3 ROOT Tool
-----------------------
このツールはMTK CPUの脆弱性をついたツールであり、簡単にROOT権限が取得できます。
(チャレンジパッド3のみ動作確認しており、将来Benesseに対策される可能性があります。)

-----------------------
条件
-----------------------
1.Androidセキュリティパッチレベルが2019年以下であること

2.チャレンジパッド3とデータ通信ができるUSBケーブルを持っていること

3.USB付きのWindowsPCを持っていること

この3つです。

-----------------------
使い方
-----------------------
USBケーブルでチャレンジパッド3とPCを接続してください。
チャレンジパッド3はUSBデバッグをONにしていてください。

ChallengePad3 ROOT Tool.batを実行します。
チャレンジパッド3に、「USBデバッグを許可しますか?」と表示されるので、
「このパソコンからのUSBデバッグを常に許可する」にチェックを入れてOKを押してください。
勝手に処理が進んでいき、ROOT権限の取得を試みます。

ROOT権限が取得できている場合は
プロンプト部分が「TAB-A04-BR3:/data/local/tmp #」、
できていない場合は「TAB-A04-BR3:/data/local/tmp $」となります。
「TAB-A04-BR3:/data/local/tmp $」の場合は対策されていますので、他でのROOT化方法をお試しください。

ROOTになったら、あとは何でもし放題です。おめでとうございます。

ドライバーフォルダは、端末が認識しないときにお試しください。

-----------------------
注意
-----------------------
ROOTになっても、exitすると普通に戻ってしまいます。
再度ROOTになる場合は、このツールをもう一度実行してください。
